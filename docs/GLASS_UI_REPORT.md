# DailyValue Mini v0.2.0 Glass UI 视觉报告

- 版本：v0.2.0
- 视觉基线：Android DailyValue 紫黑毛玻璃风格
- 渲染：Skyline + glass-easel（主验证）；视觉等价降级方案可回退 WebView
- 截图：`docs/screenshots/01–07`（iPhone 12/13 模拟器，390×844）

---

## 一、废弃与重建

v0.1.0 的「白底 + 微信绿 + emoji 堆叠 + 底部原生 tabBar」方向已废弃。v0.2.0 重建为 Android DailyValue 同一套视觉语言：

- 紫黑深色背景（背景色 `#0f172a` / `#05060a`，深色 Surface `#1a2236`）；
- 紫色主调（`#7c86ff`，深色侧 `#5b67f0`）+ 柔光；
- 半透明玻璃卡片：半透明 Surface + 渐变 + 边缘高光 + 轻阴影 + 背景透出；
- 金额语义色：支出绿 `#3ddc8f`、收入红 `#ff6b6b`；
- 主按钮紫色渐变 `linear-gradient(135deg,#7c86ff,#5b67f0)`。

按规划，**未使用高风险实时 blur hack**；Skyline 下毛玻璃以半透明叠加、渐变、阴影表达视觉等价，保证稳定性与 WebView 可降级。

## 二、主 Shell（顶部结构，非底部 TabBar）

取消原生底部「明细 / 记账 / 统计」，改为与 Android 一致的顶部结构：

```
每日的价值            [搜索账单]        设置
        统计      记账      日价
```

- 默认进入「记账」。
- 采用「一个 Main Shell + 三个 Panel/Component + Swiper」，左右滑动在「统计 ←→ 记账 ←→ 日价」间切换，不使用多页面 `navigateTo` 堆叠页面栈。
- 自定义 Header 依据 `device.js` 避让状态栏与微信胶囊（见 `IOS_COMPAT_REPORT.md`）。

## 三、三 Panel 完成度

- **记账 Panel（本阶段做完整）**：月份切换（左右箭头）、本月支出 / 收入 / 结余、账单按天分组列表、空态、玻璃 FAB（+）。
- **统计 Panel**：高质量玻璃空态 + 基础月度数字（年度统计、图表等后续版本）。
- **日价 Panel**：玻璃空态（日价详情、曲线后续版本）。
