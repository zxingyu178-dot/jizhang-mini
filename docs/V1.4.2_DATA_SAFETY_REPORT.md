## 2. 修复内容

### 2.1 删除失败检测（P0）

**问题**：`fs.remove()` 失败返回 `false`，恢复 / 回滚旧代码不检查返回值，仍继续写入；可能出现 A+B+C 叠加且条数校验通过。

**修复**：

- `data/fs.js` 新增 `removeStrict(path)`：
  - 文件不存在 → 成功；
  - unlink 抛错 / 未抛错但文件仍存在 / 无法确认已删除 → `FILE_DELETE_FAILED`；
  - 只有明确 ENOENT 且当前不可见才接受为已删除（fail-closed）。
- `data/ledger.js` 新增 `removeMonthFileStrict(ym)`：统一转为 `MONTH_DELETE_FAILED`。
- `data/backup.js` 恢复 / 回滚改为**精确替换**：
  1. 目标账单按月份分组；
  2. **只删除目标月份之外的分片**（每个月严格确认删除成功）；
  3. 目标月份用 `writeMonthFile` 原子覆盖，不依赖 unlink，也不会与旧账单叠加；
  4. 严格回读对账。

这样即使某个「多余月份」删除失败，也会在写入新账单之前中止，不会出现 A+B+C。

### 2.2 安全点完整结构校验（P0）

`rollback()` 在任何删除之前调用 `validateSafetyPoint(saved)`：

| 检查 | 失败码 |
| --- | --- |
| envelope：`format` / `schemaVersion` | `ROLLBACK_SAFETY_INVALID` |
| `data` 对象存在 | 同上 |
| `bills` 必须数组 | 同上 |
| 每个 bill 必须是对象、必须有非空字符串 `id` | 同上 |
| Bill ID 不得重复 | 同上 |
| `categories` 必须数组 | 同上 |
| `settings` 必须对象 | 同上 |
| `recurringRules` 如存在必须数组 | 同上 |
| 复用 `backupValidator.validateBackupRaw()` 做语义校验 | 同上 |

安全点不可读（JSON 损坏）→ `ROLLBACK_SAFETY_UNAVAILABLE`。两类错误都不删除任何当前文件、不删除安全点。

### 2.3 恢复 / 回滚后精确对账（P0）

新增 `verifyLedgerExact(expectedBills, code)`：

- 用 `ledger.readAllBillsStrict()` 严格回读（任一损坏月份直接失败）；
- 比较**数量、ID 集合、关键字段签名**；
- 关键字段：`id / type / amountCents / occurredAt / categoryId / ledgerImpact / sourceTxnId / title / merchant / note / dailyValue.startDate / recurringRuleId`；
- 额外检测重复 ID；
- 不一致 → `RESTORE_INTEGRITY_FAILED` / `ROLLBACK_INTEGRITY_FAILED`，错误对象记录 `expectedCount / actualCount / missingCount / extraCount / mismatchedCount / duplicateIdCount`。

签名用 `JSON.stringify([...])`，避免分隔符碰撞。

### 2.4 元数据核对（P1）

新增 `verifyMetadata(data, code)`：

- 分类文件必须是数组且条数与备份一致；
- 设置文件必须是对象；
- 周期规则必须是数组且条数与备份一致；
- 失败 → `RESTORE_META_INTEGRITY_FAILED` / `ROLLBACK_META_INTEGRITY_FAILED`，触发回滚。

### 2.5 回滚写入失败明确报告（P1）

回滚中任一步写入失败（月份 / 分类 / 设置 / 规则）不再静默：

- 错误对象保留 `rollbackAttempted=true`、`rollbackCompleted=false`；
- 附 `rollbackError.code`；
- 安全点始终保留；
- 不再谎报 `rollbackCompleted=true`。

### 2.6 错误码汇总

| 错误码 | 含义 |
| --- | --- |
| `RESTORE_DELETE_FAILED` | 恢复时多余月份删除失败，已中止写入 |
| `RESTORE_INTEGRITY_FAILED` | 恢复后账单集合 / 字段对账不一致 |
| `RESTORE_META_INTEGRITY_FAILED` | 恢复后分类 / 设置 / 周期规则核对不一致 |
| `ROLLBACK_SAFETY_UNAVAILABLE` | 安全点不可读（JSON 损坏 / 文件缺失） |
| `ROLLBACK_SAFETY_INVALID` | 安全点结构 / 语义不合格 |
| `ROLLBACK_DELETE_FAILED` | 回滚时多余月份删除失败 |
| `ROLLBACK_INTEGRITY_FAILED` | 回滚后账单集合 / 字段对账不一致 |
| `ROLLBACK_META_INTEGRITY_FAILED` | 回滚后元数据核对不一致 |
| `MONTH_DELETE_FAILED` | 单个分片严格删除失败（底层） |
| `FILE_DELETE_FAILED` | 文件严格删除失败（底层） |
