## 1. 主题矩阵（核心）

逐一验证以下组合，重点看：**状态栏文字、微信胶囊周边、页面切换、返回动画、冷启动**。

| 组合 | App 主题 | 系统主题 | 应看到 | 结果 |
| --- | --- | --- | --- | --- |
| M1 | 深色 | 深色 | 全深色，状态栏白字 | ☐ |
| M2 | 深色 | 浅色 | 内容仍深色（手动不跟随），状态栏 / 窗口不被系统改白 | ☐ |
| M3 | 浅色 | 深色 | 内容仍浅色（手动不跟随），状态栏 / 窗口不被系统改黑 | ☐ |
| M4 | 浅色 | 浅色 | 全浅色，状态栏黑字 | ☐ |
| M5 | 跟随系统 | 深色 | 内容深色 | ☐ |
| M6 | 跟随系统 | 浅色 | 内容浅色 | ☐ |

操作要点：

- **M2 / M3（手动主题 vs 系统主题不一致）最易暴露 Native Chrome 问题**：切换系统主题后回到小程序，确认内容主题不变、原生窗口颜色被 Chrome Guard 重守（无半黑半白、无白字白底）。
- **M5 / M6**：在 system 模式下实时切换系统深色 / 浅色，内容应实时跟随；若切换发生在小程序后台，回前台由 `refreshSystemTheme` 校准。

### 2.1 键盘白条专项（历史问题回归）

- 分类管理：添加分类 → 点名称输入框 → 键盘弹出 → **不关闭键盘直接关闭 Sheet** → 再收键盘：页面必须恢复原位置，无白条、Header 不位移。
- 分类管理：键盘弹出 → **直接点左上返回**：返回上一页无白屏 / 位移。
- 周期 Sheet：同样流程（输入框 → 关 Sheet / 直接返回），不复发。
