# Android 真机验收 Gate · DailyValue Mini v0.3.1

> v0.3.1 暂停 v0.4 日价开发，先完成 v0.3 统计正式版的**真实验收**。
> 真机 Gate 由你在 Android 手机微信里执行，助手不代签；Node 单测 / 模拟器通过不等于真机通过。
> 使用你当前已导入的微信 / 支付宝真实数据验证。真实账单只在手机本地，不入库、不发文件、不发邮件。

## 一、本版修复（两处口径）

1. **年度月均支出**：不再固定 `全年支出 / 12`；改为 `有支出月份的总支出 / 有支出月份数`（仅统计该月支出 > 0 的月份）；全年无支出为 0。
2. **分类支出 Top5 明细**：点击支出分类后，明细**只显示 `type==='expense'` 的账单**，同分类下的收入不得混入。
