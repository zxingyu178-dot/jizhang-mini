### 3.1 根因（唯一真凶）

**SVG 里的 `hsl()` 颜色会让对应的 `<circle>` 被 Skyline 整条丢弃。**

- 决定性对照：`real_hex_wh`（✅ 完整圆环）与 `real_hsl_wh`（❌ 全空）**只差颜色格式**，其它属性逐字相同。
- 「整张图空白」而非「缺一段」：当**所有** circle 都是 hsl 时，画面完全没有环；而 A0 里 hsl 分段全丢、`rgba` 轨道还在 → 用户看到的就是「一圈灰环 + 空白」。
- 与官方文档一致（SVG 支持有限、不支持 rgba、不支持百分比单位），但**官方文档没有提到 hsl 会连元素一起丢**，这是本次实测新增的结论。

### 3.2 顺带确认（与网上常见猜测相反）

- **宽高不是根因**：`real_hex_wh` 与 `real_hex_noWH` 像素完全相同。
- **`rgba()` 在当前工具版本里能画**：`track_rgba_only` 有可见灰环、`rgba` 的 alpha 生效（M vs I vs L 三档亮度递增）。仍按官方文档改成 hex + `stroke-opacity`，是为了规避真机/其它版本上的差异风险，不是为了修当前故障。
- **`opacity` 与 `stroke-opacity` 等价可用**：H 与 H' 像素完全相同，故选中态变淡逻辑保持原样（用 `opacity`），不做无证据的改动。

## 六、未验证 / 已知限制

1. **真机（iOS/Android）未验证**：本次门槛是「开发者工具里可见」。真机 Skyline 的 SVG 光栅化实现可能与本机不同，建议真机 Gate 时复看一眼圆环。

3. **`hsl()` 丢元素的确切边界**（是否所有 hsl 语法都丢、是否与色相数值有关）未穷举，只证明了「本工程实际产出的 `hsl(H, 62%, L%)` 会丢」。既然输出已全是 hex，此边界不影响本工程。
4. `preserveAspectRatio` / `width` / `height` 已补，但**它们不是本次根因**（有/无像素完全相同），属于防御性改动。
