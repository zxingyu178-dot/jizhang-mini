## 1. 范围

**做**：每日花费柱状图、年度 12 月柱状图、累计趋势折线、日价曲线 —— 让它们与环形图共享同一套明暗语言。

## 2. 三条抽象规则（本套语言的定义）

来自 `docs/design/chart-light-spec.md` §1：

1. **只在一根色轴上做明度台阶，最多 5 档，档与档之间是硬边（无过渡）**。色相一位不动，只有「本色 → 混白」与「本色 → 混黑」两个方向。
2. **台阶在「截面」方向上排布，不在「长度」方向上排布**。环形图是沿半径，柱状图是沿柱高，折线是沿线粗。**长度方向（弧长 / 时间轴 / 折线走向）一律不加明暗** —— 那等于在图上多画了一条假趋势。
3. **最外那一档必须是本色，不许让高光顶到轮廓线上**。浅色下混白 40% 后只有 2.01:1，柱子轮廓会消失，读高度就变成猜。

## 3. 四张图的做法

### 3.1 柱状图（每日花费 + 年度 12 月）= WXML + WXSS

`components/statistics-panel/statistics-panel.wxss` 的 `.bar--exp`：

```css
background-color: var(--primary);
background-image: linear-gradient(180deg,
  var(--bar-none) 0%,  var(--bar-none) 3%,     /* 顶倒角：本色，保轮廓 */
  var(--bar-cap) 3%,   var(--bar-cap) 8%,      /* 顶光 */
  var(--bar-lit) 8%,   var(--bar-lit) 15%,     /* 受光 */
  var(--bar-none) 15%, var(--bar-none) 80%,    /* 柱身：本色 */
  var(--bar-shade) 80%, var(--bar-shade) 93%,  /* 背光 */
  var(--bar-foot) 93%, var(--bar-foot) 100%);  /* 接触暗 */
```

档位值（`app.wxss`，深浅两套）：

| 变量 | 深色 | 浅色 |
|---|---|---|
| `--bar-cap` 顶光 | `rgba(255,255,255,0.38)` | `rgba(255,255,255,0.40)` |
| `--bar-lit` 受光 | `rgba(255,255,255,0.16)` | `rgba(255,255,255,0.18)` |
| `--bar-shade` 背光 | `rgba(0,0,0,0.26)` | `rgba(0,0,0,0.30)` |
| `--bar-foot` 接触暗 | `rgba(0,0,0,0.48)` | `rgba(0,0,0,0.44)` |
| `--bar-plate` 槽底 | `rgba(0,0,0,0.42)` | `rgba(25,28,40,0.06)` |
| `--bar-lip` 槽口高光 | `rgba(255,255,255,0.10)` | `rgba(255,255,255,0.60)` |

**为什么用 CSS 变量而不是主题选择器**：组件是 `isolated` 样式隔离，页面级的 `.theme-dark .bar--exp` 进不来（写了静默不生效）。变量定义在 `app.wxss` 的 `page` 上，组件内能继承到。

**地面槽 `.ca__plate` 的 DOM 顺序是硬约束**：必须是 `.ca__plot` 的**第一个子节点**（DOM 顺序 = 绘制顺序）。放在网格线之后会盖住 0 档网格线，数据底线的读数依据就没了；放在之前，网格线与柱子都压在它上面，槽只在柱间空隙露出来 —— 正是要的效果。

### 3.2 累计趋势折线 = SVG 字符串 → base64 → `<image>`

同一条 `d` 描三遍：暗缘（`mixHex(color,'#000000',0.26)`，略粗）/ 本体（原色）/ 高光（`mixHex(color,'#FFFFFF',0.18)`，略细且偏移）。**+2 个 `<path>`**，数据点数组一行未动。

### 3.3 日价曲线 = Canvas 2D

同一个 path 描三遍，参数同上。**0 新增元素**（Canvas 没有 DOM）。

### 3.4 `utils/color-mix.js`（新增）
`mixHex(hex, target, t)` 纯函数。存在的原因：**SVG 内禁 `rgba()`、禁 `url(#gradient)`**，而 `stroke-opacity` 是「和底下卡片混」不是「和白色混」，两者明度结果不同，不能拿来替代。所以高光 / 暗缘必须在 JS 里算成实色 `#RRGGBB`。

## 4. 开工前先验掉的前提

柱状图依赖「**同一位置两个色标的硬停**」，没有项目内先例。动手前先在一个临时元素上试：

```
linear-gradient(to top, 红 0%, 红 33%, 蓝 33%, 蓝 66%, 绿 66%, 绿 100%)
```

结果：**三段交界是锐利直线、无过渡带**，方案成立。证据图 `chart-light-probe/hardstop_zoom_x4.png`（临时目录，未入库）。

## 7. 真机验收清单（给客户）

1. **深色模式**看统计页：四张图的明暗是否一致、有没有哪张「特别假」
2. **浅色模式**再看一遍：柱子轮廓是否清楚（重点看浅色下柱顶那条亮边会不会把轮廓吃掉）
3. 柱状图柱数较多时（月中以后）是否还能一眼数清柱子
4. 累计折线：线是否有「粗细感」，有没有出现双线 / 重影
5. 日价曲线页：曲线是否正常（这条最没底）
6. 分类占比圆环点选某一段：是否整块向外浮起、其余变暗
