## 6.0 怎么用这份清单

- 每项三列：**查什么**（要看的行为）→ **在哪查**（具体到点哪个入口）→ **什么样算通过**（判断标准）
- 每项前面有个 `[ ]`，**通过打 `[x]`，不通过打 `[!]` 并写现象**，跳过写 `[-]` 并写原因
- **一台 iPhone + 一台 Android 各走一遍**，结果分别记录
- ⛔ **不要跳项**：尤其第 6.10 节（备份与恢复）和第 6.12 节（白屏/闪退），这两块自动化覆盖不到，是本节的核心价值

| # | 查什么 | 在哪查 | 什么样算通过 |

| 6.3.4 | 删除一笔账单 | 时间线 → 点某笔 → 删除 → 确认 | 该笔消失，**总条数减 1**，统计金额同步减少 |

| 6.3.8 | 键盘遮挡 | 输入金额时弹出键盘 | 输入框和保存按钮**不被键盘挡住**，能正常点保存 |

| # | 查什么 | 在哪查 | 什么样算通过 |

| 6.4.6 | 删除规则 | 删除规则 | 规则消失；**历史账单保留**（账单是已发生的钱，不该跟着规则消失） |
| 6.4.7 | 周期规则触发重复 | 同一触发日反复进出小程序 | **同一天不会重复生成同一笔**（不出现两条一样的账单） |
