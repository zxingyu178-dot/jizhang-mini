## 1. SVG 组件审计

v1.4.0 已确认「HSL 颜色导致 Skyline 圆环不显示」，本次**不假设所有 rgba 都有问题**，逐项生成 SVG 检查。

| 组件 | 颜色写法 | 根节点 | data-URI | 深色 | 浅色 | Skyline 实测证据 | 结论 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `category-icon` | `rgba(255,255,255,0.86)` / `rgba(25,28,40,0.88)` 等 | `viewBox 0 0 24 24`，尺寸由 `boxSize/iconSize` 控制 | base64 | 正常 | 正常 | E2E T12 日价列表、T28 导入预览、T03 分类管理截图 | 无兼容问题，**不替换 rgba** |
| `icon`（dv-icon） | 同上 | `viewBox 0 0 24 24`，`w/h = size` | base64 | 正常 | 正常 | 全站 Header / 按钮图标，T25、T13–T18 均正常 | 无兼容问题 |
| `cumulative-trend` | 网格 `rgba(...)`；折线/面积 `#7c86ff` | `viewBox 0 0 100 100`，容器与 image 显式 `width/height` | base64 | 正常 | 正常 | `node tests/e2e/cumulative-view.js`：6/6 通过，points=30，data-URI 已生成并截图 | 无兼容问题 |
| `category-donut` | 内部 `hslToHex` → `#RRGGBB`；轨道 rgba | `viewBox 0 0 100 100` | base64 | 正常 | 正常 | E2E T20–T24 圆环触摸 / 钻取 / 切主题 | v1.4.0 修复保持，未回退 |

审计断言（`tests/svg-compat.test.js`，101 项）：

- 所有 SVG 输出不含 `hsl(` / `hsla(`，不含 `undefined` / `NaN` / 空 `stroke`；
- 颜色只允许 `#RRGGBB` 或 `rgba(...)`；
- 根节点必须有 `viewBox`，尺寸由 `<image>` 显式控制；
- base64 编码与标准 Base64 一致（含 1–5 字节补齐）；
- 深 / 浅主题均能生成完整 SVG；
- `donut` 保留 `hslToHex`，防止 v1.4.0 修复被无意回退。

> 结论：其他 SVG 组件在当前目标渲染器下表现正常，**未发现需要修复的真实兼容问题**；不做统一颜色替换，避免引入新风险。

## 2. 320px 统计 Hero 三列

问题：月度 Hero 第二行第三列「最高消费日」内容为 `{{mTopDay}} {{mTopDayAmount}}`（如「31日 ¥1,234,567.89」），320px 下三列等宽时可能折行。

修复（保持三列、内容完整、不改统计结果）：

```css
.hero__foot--three .hero__third:nth-child(2) { flex: 1.6; padding-right: 0; }
.hero__foot--three .hero__third .hero__sub { font-size: 26rpx; white-space: nowrap; }
@media (max-width: 360px) {
  .hero__foot--three .hero__third .hero__sub { font-size: 22rpx; }
  .hero__foot--three .hero__third:nth-child(2) { flex: 1.7; }
}
```

- 中间列获得更高弹性，日期 + 金额单行展示；
- 不使用 `text-overflow: ellipsis`、不使用 `overflow: hidden`，内容不被截断；
- 未使用 `clamp()` / `:has()` 等未验证特性，只用标准 WXSS 媒体查询。

验证：

| 检查 | 方式 | 结果 |
| --- | --- | --- |
| 三列结构 | `stats-hero-layout.test.js`：WXML 仍为 3 个 `.hero__third` | 通过 |
| CSS 契约 | flex / nowrap / 媒体查询 / 无截断 | 通过 |
| 320 / 360 / 390 / 430 宽度 | 按 rpx 换算 + 保守字符宽度估算，最坏文案不超列宽 | 4 档通过 |
| 390px 实际渲染 | **E2E T31**：注入「31日 / ¥1,234,567.89 / 9999 笔 / ¥12,345.67」，断言文本完整、`height < 30`（单行）、右边界不超卡片 | 通过 |
| 深 / 浅主题 | 本次只改布局，不改颜色；深色 E2E 截图 + 既有浅色主题用例 | 通过 |

**如实说明**：本 Gate 未重新切换模拟器到 320 / 360 / 430 机型截图（需手动改微信开发者工具机型配置）。320 / 360 / 430 采用 CSS 契约 + 宽度估算验证；390px 为真实 Skyline 渲染实测。真机四档宽度验收列入 Gate 5 清单。
