# Android 真机验收 Gate · DailyValue Mini v0.3.2

> v0.3.2 是「Android Main UI Parity」：把记账主页骨架对齐 Android DailyValue。
> 真机 Gate 由你在 Android 手机微信里执行，**助手不代签**；Node 单测 / 模拟器通过 ≠ 真机通过。
> 使用你当前已导入的微信 / 支付宝真实数据验证。真实账单只在手机本地，**不入库、不发文件、不发邮件**。

## 一、当前已由助手完成并验证的范围（模拟器，非真机）

- Node 纯函数测试：**270 项全绿（5/5，exit=0）**，含新增 accounting 45 项。
- 开发者工具模拟器（iPhone 12/13，390px）**WebView 与 Skyline 双渲染模式**均核对：
  Header、Hero、箭头切月、Hero 横滑切月、时间线、FAB、Bottom Sheet、统计页、日价空态。
- 渲染配置提交为 `"renderer": "skyline"`（`app.json` 全局 + `pages/main/main.json`）。
